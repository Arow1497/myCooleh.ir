Cooleh Project
یک سرویس بک‌اند جامع برای پروژه Cooleh با قابلیت‌های پیشرفته امنیتی، مقیاس‌پذیری و مانیتورینگ.

ویژگی‌های کلیدی

🔐 امنیت پیشرفته با استفاده از Helmet, Express-validator, XSS protection
📈 مقیاس‌پذیری با Redis و Kafka
🗄️ پشتیبانی از MySQL با Prisma ORM
📝 لاگینگ پیشرفته با Winston
🚀 مانیتورینگ با New Relic و Sentry
📹 پردازش ویدیو با FFmpeg
📧 سیستم ایمیل با Nodemailer
🔍 مستندات API با Swagger
👥 پشتیبانی از WebSocket با Socket.io
🔄 سیستم صف با Bull
⚡ Rate limiting و Brute force protection

پیش‌نیازها

Node.js >= 18.0.0
NPM >= 8.0.0
MySQL
Redis
FFmpeg
